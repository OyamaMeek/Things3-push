# Security Policy

## Supported Version

Security fixes are applied to the latest `main` branch.

## Reporting a Vulnerability

Do not include credentials, Things database content, or a proof-of-concept that mutates Things data in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available. If it is unavailable, contact the repository owner through the contact method listed on their GitHub profile and include a minimal reproduction with sensitive values redacted.

Rotate any exposed Git, Things, or operating-system credential before reporting it.
